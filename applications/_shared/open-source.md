## Athena

**Description (short)**: The ATLAS Experiment's main offline software framework at CERN.

**Description (medium)**: I contribute to Athena, the large-scale open-source software framework used by the ATLAS Experiment at CERN's Large Hadron Collider. My contributions include energy reconstruction algorithms for the Tile Calorimeter, machine-learning-based estimation tools, and detector electronics support work during Long Shutdown 2.

**My role**: Contributor since 2019, active on merge requests via the CERN GitLab (username: ginaciog).

**Link**: <https://gitlab.cern.ch/atlas/athena/-/merge_requests?state=all&author_username=ginaciog>

**Language / Stack**: C++, Python

**Signal it sends**: rigor, scientific computing, large-codebase collaboration, upstream contribution to an internationally maintained project.

## Lorenzetti

**Description (short)**: A general-purpose framework for signal reconstruction and triggering in high-energy calorimetry.

**Description (medium)**: I co-developed Lorenzetti during my PhD research: a general-purpose calorimetry simulation framework that supports novel signal reconstruction and triggering strategies. Unlike experiment-specific frameworks, Lorenzetti is designed for open use across the HEP community, enabling advanced signal processing approaches (including machine learning and stochastic models) beyond a single experiment's collaboration boundary. Published in Elsevier in 2023.

**My role**: Co-developer during PhD (2021–2026).

**Link**: <https://github.com/lorenzetti-ufrj-br/lorenzetti>

**Publication**: "Lorenzetti Showers — A general-purpose framework for supporting signal reconstruction and triggering with calorimeters" — Elsevier, May 2023.

**Language / Stack**: C++, Python

**Signal it sends**: authored contribution, published research, HEP community adoption, framework design.

## Calorimetry Pulse Simulator

**Description (short)**: A pulse generator and signal simulation library for calorimeter electronics.

**Description (medium)**: I designed and built the calorimetry-pulse-simulator library during my PhD research: a C++ core with Python bindings that enables realistic simulation of calorimeter electronic readouts. The library is used for physics studies and algorithm development, and has been adopted by multiple international research groups.

**My role**: Author and maintainer.

**Link**: <https://github.com/ingoncalves/calorimetry-pulse-simulator>

**Language / Stack**: C++ core, Python bindings.

**Signal it sends**: I ship and maintain my own open-source infrastructure. Adoption by international groups is external validation.
