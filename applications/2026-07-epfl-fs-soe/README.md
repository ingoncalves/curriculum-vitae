## Fit assessment

**Strengths (very strong overlap)**:
- **Stack overlap is excellent**: Node.js + React + PostgreSQL + Docker + Kubernetes are all daily at Siteimprove and Orkast
- **Python depth** from CERN work translates well to FastAPI (framework is different, language and idioms are shared)
- **AI-agentic workflow explicit** in the JD (mentions GitHub Copilot, internal LLM agents, agentic workflows, AI-driven testing) — direct match with daily Claude Code use at Orkast
- **DELF B2 French** — the posting requires "proficient in English and French, both written and spoken". This is a real gate; many candidates fail here. Real differentiator.
- **CERN pedigree fits EPFL culture**: peer research institution, PhD-level engineering respected, open-source contribution valued (Athena, Lorenzetti, calorimetry-pulse-simulator, Etherpad, Scilab all resonate)
- **DevOps / SRE mindset**: Orkast Terraform + Siteimprove FedRAMP/Aikido security work + monitoring practices align with the "reliability, observability, operational excellence" language of the JD
- **Client-facing framing** matches Orkast stakeholder work with CFO/CEO on v1.1.0

**Gaps**:
- **FastAPI**: no production experience specifically (Python yes, this framework no). Bar is lower than Flask at CERN — FastAPI is younger, async-first, Pydantic-based, and easier to pick up quickly. Ramp-up cost is small.
- **Ansible**: use Terraform daily, know Ansible conceptually only. Same discipline (declarative IaC), different tool.
- **Traefik**: unfamiliar. It is a modern reverse proxy / load balancer; alternative to nginx / HAProxy. Not a blocker; days to learn.
- **French**: DELF B2 is legally sufficient for the "proficient" wording, but there is a spectrum from B2 to native. Interviews may include French questions. Worth practicing before the interview stage.

**Read on likely bar**: strong fit, especially at the intersection of engineering rigor + AI-agentic tooling + French capability + Swiss/CERN cultural fit. Public sector hiring tends to be more deliberate (longer cycle) but also less filter-heavy on the "wrong keyword" auto-reject axis. Human review is likelier.

## Compensation and family context

Compared to Sonar Staff (~250k CHF total), EPFL is meaningfully lower on cash comp. But it comes with:

- **CDI (permanent contract)** — no sunset date. Enables long-term Swiss residency path (C permit after 5 years, then Swiss citizenship path).
- **On-campus daycare** — solves the crèche subventionnée waiting list problem that would apply in Geneva
- **Family allowances** — Vaud canton allocations for children, plus EPFL-specific benefits
- **Location**: Lausanne is cheaper than Geneva (rent ~20% lower for equivalent 3-bedroom), still connected to Geneva by 40-min train
- **Pension**: Confederation Suisse LPP + AVS = one of the strongest pension systems in the world
- **French language courses free for staff** — accelerates my B2→C1 progression

For a family with a 1-year-old daughter, wife not initially working, this may be the highest-utility option even if the cash number is lower. The trade-off is between higher optionality (Sonar/Proton private tech) vs higher stability (EPFL public sector CDI).
